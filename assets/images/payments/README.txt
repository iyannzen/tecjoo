TechZone - Panduan Logo Pembayaran
===================================

Taruh file logo (PNG transparan disarankan, persegi, minimal 128x128px)
di folder ini dengan NAMA FILE PERSIS seperti di bawah. Begitu file
diunggah, logo asli akan otomatis muncul menggantikan badge warna
(tidak perlu ubah kode apapun).

1) Ikon metode pembayaran (folder ini langsung):
   - qris.png            -> ikon QRIS / E-Wallet di checkout
   - cod.png              -> ikon Bayar di Tempat (COD)
   - transfer-bank.png    -> ikon Transfer Bank

2) Logo e-wallet, folder wallets/:
   - dana.png
   - gopay.png
   - ovo.png
   - shopeepay.png
   - linkaja.png
   - jenius.png

3) Logo bank (daftar statis "bisa transfer dari bank manapun"), folder banks/:
   - bca.png
   - bri.png
   - bni.png
   - mandiri.png
   - bsi.png
   - btn.png
   - cimb-niaga.png
   - permata.png
   - danamon.png
   - maybank.png
   - panin.png
   - uob.png
   - ocbc-nisp.png
   - mega.png
   - sinarmas.png
   - nagari.png

CATATAN PENTING - Rekening bank tujuan transfer (yang benar-benar bisa
dipilih pembeli saat checkout) TIDAK memakai folder ini. Logo untuk
rekening tersebut diunggah langsung lewat halaman:
  Admin > Transaksi > Rekening Bank > Tambah/Edit Rekening
(otomatis tersimpan ke folder uploads/banks/, tidak perlu diatur manual).


3) CATATAN: e-wallet kini dikelola dari Admin > Rekening & E-Wallet > E-Wallet
   (unggah logo langsung di sana). File di folder wallets/ hanya dipakai bila
   e-wallet belum punya logo unggahan. Bank juga bisa diunggah logonya dari Admin > Rekening Bank.
